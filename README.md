# UC‑1: Employee Registration
## What it does
Registers a new employee and saves the details in a file.
## Main Steps

- Take employee details
- Validate email, phone, and employee ID
- Create UserAccount
- Create Employee
- Save data to employee_data.txt
- Show success message

## Packages
- com.app
- com.model
- com.exception

## Goal
Store valid employee details safely.
