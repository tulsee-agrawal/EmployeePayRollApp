# UC‑2: Employee Authentication & Login
## What it does
Authenticates a user, starts a session, and reports if the session is active.
## Main Steps

- Register user (take input)
- Login with username & password
- Create a Session on success
- Print session details
- Check if session is expired

## Key Ideas

- Inheritance & polymorphism
- Abstract class
- Method overriding
- Runtime decisions

## Packages

- com.app – Main app (App)
- com.auth – AuthenticationService
- com.session – Session
- com.model – UserAccount, Employee
- com.exception – ValidationException


## Goal
Allow valid users to log in and obtain an active session.
